# Tasks — 開發暫停紀錄與 Google Calendar 設定指南

## 現況

這個 repo 原本規劃做一個自訂日曆 App，用來處理：

1. 自動跑出上班日（做二休二班表）
2. 手動加入加班日
3. 手動輸入重大事件（Fed 升息會議、WWDC…），並希望能自動加入
4. 手動輸入當天任務
5. 自動跑國定假日（中秋、端午…）
6. 股市除權息日自動加入
7. 每月固定信用卡繳款日提醒

**結論：第 1、2、4、5、7 項用 Google Calendar 原生功能就能達成，不需要客製化開發。因此整體 App 開發先暫停。** 只有第 3、6 項（自動抓外部資料寫入日曆）是現成日曆做不到的，未來如果要做，會是獨立的小型自動化工具，而不是整套日曆系統。

## 各項需求對應設定方式

### 1. 做二休二上班日（自動產生）

Google Calendar 支援「自訂重複」：

1. 新增一個**全天事件**，時長設為 2 天（例如上班日 9/20–9/21）
2. 重複設定選「自訂」→「每 4 天」重複一次
3. 系統會自動延伸出 2 上 2 休的循環班表

若排班起點改變，只要調整第一個事件的起始日即可，不用重寫整個規則。

### 2. 手動加入加班日

直接在對應日期手動新增一個事件（例如「加班」），可加上顏色標籤與提醒時間，跟平常用法一樣。

### 3. 手動輸入重大事件（希望能自動加入）

- **手動輸入**：直接新增事件即可，例如「Fed FOMC 會議」「WWDC」。
- **自動加入**：Google Calendar 沒有原生功能可以自動抓這類財經/科技事件。要做到自動化，需要一個獨立小工具，定期（例如每天/每週）從資料來源（如 Fed 官網會議行事曆、Apple Newsroom、財經日曆 API）抓取事件，再透過 Google Calendar API 寫入你的日曆。**這是唯一值得未來開發的部分之一。**

### 4. 手動輸入當天任務

用 Google 「工作」(Tasks) 或直接在該日新增事件都可以，兩者都會顯示在日曆上。

### 5. 自動跑國定假日（中秋、端午）

Google Calendar 內建「其他日曆」→「感興趣的日曆」可直接訂閱「台灣的假日」公開日曆，中秋、端午、國定假日都會自動顯示，不需要手動輸入或開發。

設定路徑：Google Calendar 左側「其他日曆」旁的「+」→「訂閱日曆」→搜尋「台灣假日」。

### 6. 股市除權息日自動加入

Google Calendar 沒有現成的除權息日曆可訂閱。要自動化，需要：

1. 定期從證交所 / 公開資訊觀測站 / 券商 API 抓取你持股清單的除權息日期
2. 透過 Google Calendar API 自動寫入你的日曆

**這是另一個值得未來開發的獨立小工具。**

### 7. 每月固定信用卡繳款日

新增一個事件，重複設定選「每月」，指定當月的第幾天（或第幾個星期幾）即可自動每月重複提醒，不需要開發。

## 後續建議

如果之後想做第 3 項或第 6 項的自動化工具，建議做成：

- 一個排程執行的小腳本（cron job / GitHub Actions），
- 串接 Google Calendar API 寫入事件，
- 不需要自己蓋資料庫或前端介面，因為顯示介面直接用 Google Calendar 就好。

需要的話可以再另外開新的開發任務處理這兩項。

# Tasks — 個人日曆 App

輪班（做二休二）、加班、重大事件、任務、國定假日、除權息、信用卡繳款日的個人日曆工具。

## 使用方式

純前端、沒有 build 流程，用瀏覽器開 `index.html` 即可（或起一個簡單的靜態伺服器，例如 `python3 -m http.server`）。所有資料存在瀏覽器的 localStorage。

## 目前功能

1. **上班日自動產生**：設定裡填「起始日 + 連續上班天數 + 連續休假天數」（預設做二休二），自動延伸整個月的班表
2. **加班日**：點任一天，勾選「今天加班」
3. **重大事件**：點任一天手動輸入（例如 Fed FOMC 會議、WWDC）
4. **當天任務**：點任一天新增待辦清單，同一天可以有多筆，各自勾選完成、可個別刪除
5. **國定假日**：內建 2026 年台灣行政機關辦公日曆表（`js/holidays.js`），逐年手動維護
6. **股市除權息**：目前手動輸入，記在對應日期
7. **信用卡繳款日**：設定裡填每月幾號，自動每月標示提醒

## Roadmap
